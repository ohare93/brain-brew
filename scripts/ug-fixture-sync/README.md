# Ultimate Geography fixture sync

Run `scripts/sync-ug-fixture.sh /path/to/ultimate-geography` whenever the upstream Ultimate Geography checkout moves and Brain Brew's parity fixture should follow it. The script copies fixture-relevant source files one way from UG into `fixtures/ultimate-geography/` (manifests, deck sources, overlays, descriptions, templates, and styles; full media binaries are intentionally excluded because current tests validate declared media references rather than asset bytes), reapplies Brain Brew's temporary ADR-0012 manifest delta, and runs `brainbrew fmt` over the copied fixture so the checked-in source is canonical under the current emitter. That delta lives in the `*.adr-0012.yaml` fragments in this directory: it adds `languages:` and `translation_profile:` catalogs for Workbench/translation coverage until UG adopts those fields upstream, at which point the fragments and splice step can be deleted. The sync remains one-way: it never writes back into the Ultimate Geography checkout.
