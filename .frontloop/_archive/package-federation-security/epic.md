## Goal

Ensure every package, manifest, include, overlay, media file, and lock entry is contained, authenticated, provenance-aware, and processed within bounded resource budgets. Unify package planning so all CLI and Workbench routes enforce the same dependency rules.

## Sequence

Choose symlink and compatibility policy, close path/hash escapes, add bounded fetching, consolidate planning and validation, then add media ownership and scalable discovery.
