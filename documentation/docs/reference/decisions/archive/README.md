# Archived ADRs

These ADRs record the pre-fresh-start Brain Brew architecture. They are kept for historical context, but the active implementation direction starts with ADR-0011 in the parent directory.

The archived decisions include the earlier Gren-first, CanonicalNote-first, web-first, and live sync-oriented design. New work should follow the active ADRs unless deliberately revisiting one of these historical choices.
