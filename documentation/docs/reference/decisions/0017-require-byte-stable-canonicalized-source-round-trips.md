# ADR-017: Require Byte-Stable Canonicalized Source Round Trips

**Date**: 2026-05-22  
**Status**: Accepted  
**Deciders**: Project Lead

## Context

Round-trip fidelity can mean anything from loose note-content equivalence to exact reproduction of arbitrary source bytes. Exact preservation of arbitrary imported formatting would make CSV quoting, blank lines, and incidental layout dominate the design.

## Decision

Round trips must reproduce byte-for-byte **canonicalized source**: source files after Brain Brew has applied its deterministic formatting rules. Arbitrary original input formatting does not need to survive once normalized.

## Rationale

Deck maintainers need stable diffs and confidence that unchanged data stays unchanged. Byte-stable canonicalized output gives that without requiring the system to preserve every incidental formatting choice from pre-existing files.

## Implications

- Source writers must be deterministic.
- Fixtures can assert exact generated bytes after normalization.
- Importing legacy source may produce a one-time formatting change.
