# Install the CLI

Brain Brew is a Rust CLI named `brainbrew`.

The primary install path is a prebuilt GitHub Release binary. You do **not** need Rust or Nix to test a released Brain Brew build. Deck projects such as Ultimate Geography can link to this page and recommend a specific Brain Brew release tag instead of asking contributors to run Brain Brew through a Nix flake.

## Recommended version for deck contributors

Use the version recommended by the deck repository you are contributing to. For the current Brain Brew preview, pin examples and contributor docs to `v1.0.0-alpha.1` and verify the installed binary with:

```bash
brainbrew --version
```

If a deck needs a newer Brain Brew behavior, update its docs to name the new Brain Brew tag or release URL. Nix users can still pin a flake revision for reproducible CI, but normal deck editing should start from the release installer, Homebrew, or Cargo install commands below.

## GitHub Release installer

macOS and Linux:

```bash
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/jeprecated/brain-brew/releases/download/v1.0.0-alpha.1/brainbrew-installer.sh \
  | sh
brainbrew --version
```

Windows PowerShell:

```powershell
irm https://github.com/jeprecated/brain-brew/releases/download/v1.0.0-alpha.1/brainbrew-installer.ps1 | iex
brainbrew --version
```

The installer is generated by `cargo-dist` and downloads the correct archive for your platform.

## Homebrew

If you use Homebrew on macOS or Linux:

```bash
brew install jeprecated/tap/brainbrew
brainbrew --version
```

The Homebrew formula is generated from the same release artifacts as the shell installer.

## Cargo install

If you already have Rust installed, install the pinned release from crates.io after the preview crate is published:

```bash
cargo install brainbrew --version 1.0.0-alpha.1 --locked
brainbrew --version
```

Before the crates.io package is published, or if you need to test the exact GitHub tag, install directly from the same release tag:

```bash
cargo install --git https://github.com/jeprecated/brain-brew --tag v1.0.0-alpha.1 brainbrew --locked
brainbrew --version
```

Both commands are normal non-Nix install paths, but the prebuilt release installer is preferred for users who do not already have Rust.

For unreleased branch testing:

```bash
cargo install --git https://github.com/jeprecated/brain-brew --branch rust-brainbrew brainbrew --locked
```

## Nix, optional

Nix is useful for contributors and reproducible CI, but it is not required for deck maintainers testing Brain Brew.

From the Brain Brew checkout:

```bash
nix run . -- --help
```

From another deck workspace:

```bash
nix run /path/to/brain-brew -- targets --manifest brainbrew.yaml
```

Build a local binary:

```bash
cd /path/to/brain-brew
nix build .#brainbrew
./result/bin/brainbrew --help
```

Install into a Nix profile:

```bash
cd /path/to/brain-brew
nix profile install .#brainbrew
brainbrew --help
```

## Developer shell

The repository uses Devenv for day-to-day development. With direnv, `.envrc` loads the environment automatically; otherwise run commands through `devenv shell`:

```bash
devenv shell test
devenv shell ci
devenv test
```

## Runtime dependencies

The CLI is intended to run natively. Nix is an install/build option, not a runtime requirement for package locking. `brainbrew lock update` computes NAR hashes and fetches path/tarball/GitHub inputs in Rust.
