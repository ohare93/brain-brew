# brain-brew-formats

Internal YAML and CrowdAnki codec implementation package for [Brain Brew](https://github.com/jeprecated/brain-brew), a local-first deck federation tool. It is published only to support the `brainbrew` CLI and has no supported public Rust API commitment.

See the [project README](https://github.com/jeprecated/brain-brew#readme) for installation and release guidance.
